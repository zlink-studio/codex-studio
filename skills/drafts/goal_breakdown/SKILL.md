# Goal Breakdown

## suitable_agents

Executive, Product

## when_to_use

Use when an owner goal is still broad and needs to become a task plan.

## inputs

- goal
- project context
- approved memories

## outputs

- task list
- priority order
- risk notes
- next action

## workflow

1. Clarify the intended outcome.
2. Break work into task-sized units.
3. Flag dependencies and approvals.
4. Return a concise execution plan.

## risk_level

low

## approval_required

false

## source_references

- internal design
- openai/skills `define-goal`

## notes

Do not invent approvals or commitments without evidence.
