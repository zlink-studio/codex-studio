# ZLink Studio OS — UI Concept

高保真桌面端原型，用于确定 Phase B.5「客户运营 OS」的产品结构和视觉方向，暂不替换现有生产界面。

## 视觉方向

- Linear：暗色原生、精密信息层级、低对比边框、克制的紫色交互强调。
- Superhuman：暖白主按钮、强主标题、宽松页面节奏和高级产品感。
- 中文界面优先，Inter 与系统中文字体混排。
- 8px / 16px 两级圆角，避免泛滥的玻璃拟态、巨大圆角和装饰性渐变。

## 页面

1. 今日驾驶舱：工作室总览、客户健康、审批和实时执行。
2. 客户中心：客户、服务组合、未来交付和健康状态。
3. 客户运营空间：单客户的服务、KPI、上下文与客户经理 Agent。
4. 服务运营：跨业务状态机和工作单看板。
5. 运营日历：Playbook 自动生成的周期工作承诺。
6. 老板收件箱：批量审批、风险、异常和授权范围。
7. Agent 团队：岗位组织、实时负载、模型与执行留痕。

## 查看

在本目录运行：

```bash
python3 -m http.server 4177 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4177/`，通过左侧导航切换页面。

`screenshots/` 内为 1440×1000 的验收设计图。
