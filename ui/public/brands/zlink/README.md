# ZLink supplied brand assets

Provided by the workspace owner for the ZLink trial. Original file: `Gemini_Generated_Image_yyaxdryya.png` from the supplied logo folder.

The existing black Z symbol is retained. Web preparation uses a centered 1536×1536 crop of the 2048×2048 source, then resamples to 512, 192, 180, 48, 32 and 16 pixels. The 48-pixel image is also encoded as ICO. No mark is redrawn; the supplied light background provides contrast on both browser themes. `mark.png` is the 512-pixel master used by the home header and uploaded through the native company-logo settings for the sidebar.

The custom frontend references this directory explicitly so previously cached upstream icon URLs are not reused. The app manifest references the same supplied mark for installed shortcuts.
