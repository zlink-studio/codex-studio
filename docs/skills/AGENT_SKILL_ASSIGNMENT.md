# Agent Skill Assignment

## Executive Agent

- `goal-breakdown`: turns owner intent into executable tasks.
- `review-gate`: catches high-risk or approval-sensitive work before execution.
- `memory-capture`: proposes durable knowledge from planning and review outcomes.

## Growth Marketing Agent

- `content-planning`: generates topics, channels, and conversion actions.
- `seo-brief`: remains disabled until source and license review is complete.
- `ads-analysis`: supports campaign diagnosis and test planning.

## Operations Agent

- `implementation-planning`: converts delivery requirements into execution checklists.
- `automation-dispatch`: stays approval-gated and does not execute external systems automatically.
- `memory-capture`: preserves SOP and delivery learnings.

## Finance / Reviewer Agent

- `review-gate`: primary review skill for approvals, contracts, and high-risk outputs.
- `outbound-sales-drafting`: optional and disabled by default because it may affect external communication.

## Product Agent

- `implementation-planning`: breaks specs into build and QA steps.
- `review-gate`: validates release readiness for sensitive changes.
- `data-cleanup`: helps normalize structured product or operations data.
